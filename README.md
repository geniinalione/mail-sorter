# Mail Sorter

Автоматическая система сортировки корпоративной почты. Читает письма из папки `data/inbox/`, распределяет их по категориям и раскладывает по папкам `output/<категория>/`.

## Установка

```bash
pip install -r requirements.txt
```
## Запуск

1. Положите письма (текстовые файлы) в папку `data/inbox/`, затем:
2. Скрипт проверяет наличие `data/inbox/`, запускает скрипт, сортирует и выводит статистику сортировки.

```bash
bash run.sh       #Если у вас мак.
```

Запустить напрямую через Python:
```bash
python -m mailsorter.pipeline       #Если у вас Windows
```

## Формат письма

Файл письма — текст в свободной кодировке. Заголовки отделяются от тела письма пустой строкой. Поддерживаются заголовки на русском и английском языках:

```
From: sender@company.ru
Subject: Запрос доступа

Текст письма...
```

Поддерживаемые варианты: `From` / `От кого` / `Ot kogo`, `Subject` / `Тема` / `Tema`.

## Категории

| Категория       | Описание |
|----------------|----------|
| `notifications` | Дайджесты, созвоны, плановые рассылки |
| `spam`          | Рекламные и фишинговые письма |
| `critical`      | Критические сбои, массовые инциденты |
| `automated`     | Автоматические уведомления от систем |
| `finance`       | Счета, оплата, реквизиты |
| `hr`            | Отпуска, больничные, графики |
| `external`      | Письма с внешних (не корпоративных) доменов |
| `support`       | Запросы доступа, технические проблемы |
| `unsorted`      | Письма, не подошедшие ни под одну категорию |
| `corrupted`     | Нечитаемые или повреждённые файлы |

Категории проверяются именно в этом порядке, приоритет убывает сверху вниз.
